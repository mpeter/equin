# github-issues

GitHub new-issue links, built in plain JS (`core/`, every host): a request
written in a draft field becomes a prefilled `<repo>/issues/new?title=…&body=…`
link the user opens themselves. Nothing here talks to GitHub — the link hands
off to GitHub's own form, so it needs no token and works for anyone.

Used by the website's Wish (`apps/website/improve`) and the app's Wish popover
(`wish/github-issue`). Each host passes its own `notes` (lines closing the body:
a choice the user made, where it was filed from) and `labels`.

**The issue reads as prose; the picks ride below it.** `readableIdea` turns each
`<ui-context>` tag in the text into `` `<label>` [n] ``, and the title and the
body are built from that, never from a raw tag. It splits with
`splitUiContext` because only `ui-context` may name the token's pattern
(`no-token-identity-outside-owner`). Under the body's rule, each pick gets a
`<details>` block holding its raw tag for an agent. The tag sits in a code
fence, or GitHub strips it as HTML, and the blank lines around the fence are
what make GitHub render it inside `<details>`.

**A draft that does not share its page sets `omitPickUrls`.** Each pick's tag
carries the `url` of the page it was picked on, so leaving out the `Page:` line
alone would still leak it; the flag drops that attribute (via the token owner's
`withoutUiContextUrl`) from the readable text and the collapsed blocks, keeping
the rest of each pick.

**`buildIssueUrl` keeps the link under 7,500 characters** (GitHub rejects longer
ones). A tag runs to several hundred characters, so the tags go before any word
the user wrote. When the whole issue is too long, it gives up, in order:

1. the raw tags, last pick first (that pick keeps a plain `[n] <label>` line);
2. the end of the user's text, which is then ended with "…";
3. the trailing `[n]` lines, counted instead as "+N more".

It never cuts the title, the page or the notes, and throws only when those
alone are over the cap. Labels apply only for a filer with triage rights on the
repository; everyone else files unlabelled.
